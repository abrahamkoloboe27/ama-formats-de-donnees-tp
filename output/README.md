# Dossier `output/`

Vide dans le dépôt : chaque notebook y écrit les fichiers qu'il produit (CSV, Excel, JSON, Parquet, tables Delta et Iceberg). Git ignore son contenu.

Comptez environ **1,5 Go** une fois tous les notebooks exécutés (le CSV du mois complet pèse à lui seul 425 Mo). Vous pouvez vider ce dossier à tout moment : relancer les notebooks le reconstruit.
